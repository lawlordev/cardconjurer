# Set Conjurer v0.1.0-beta.4

Set Conjurer beta.4 makes large card sets practical, preserves artwork placement reliably, and includes a focused set of editor and export fixes.

## Highlights

- Scale card workspaces to approximately 1,000 cards with large uploaded artwork by storing artwork once, persisting normalized card data incrementally, and keeping bounded change history.
- Migrate beta.3 workspaces automatically while retaining the legacy recovery document and original content-addressed artwork files for rollback.
- Preserve artwork position and zoom across card changes, undo and redo, save and reload, and portable card or set export.
- Restore set image ZIP downloads, including cancellation safety and themed exports.
- Keep collector numbering, land-frame selection, and per-card text sizing accurate as cards are edited or renumbered.
- Correct Planeswalker frame behavior, card-row metadata dividers, inline mana-symbol wrapping, and advanced-section styling.
- Allow exports without an artist credit, animate card creation and deletion, and improve keyboard flow through the Text tab fields.

## Upgrade notes

- Existing beta.3 profiles are migrated on first launch. Back up important work before installing any beta build.
- The migration intentionally retains beta.3 recovery data and does not garbage-collect user artwork during this release line.
- Frame-pack compatibility is unchanged from beta.3; beta.4 continues to use the existing compatible pack catalog.
- This is a prerelease. Windows trust warnings remain possible when Azure Artifact Signing is not configured for the release run.

## Validation focus

- Upgrade a copied beta.3 profile containing multiple cards and large uploaded artworks. Confirm artwork loads, editing and undo work, state survives restart, and exported cards and sets retain usable embedded artwork.
- Open the deterministic 1,000-card fixture and select cards near the start, middle, and end before and after editing, undoing, and restarting.
- Verify image ZIP export, collector renumbering, automatic land-frame updates, Planeswalker frames and stamps, text-size isolation, mana-symbol wrapping, artist-free export, advanced sections, and Text-tab keyboard order.
- Install the Windows Setup artifact and perform an N-1 upgrade with a disposable user profile. Confirm workspace data, active packs, shortcuts, Installed Apps registration, and the running version survive the upgrade.
